Famify

O Famify é uma aplicação web desenvolvida para facilitar o matchmaking de famílias Steam, conectando usuários com interesses em jogos semelhantes para a formação de grupos de compartilhamento de jogos, respeitando as regras da plataforma Steam.

Este repositório contém a camada de frontend, responsável pela interface do usuário, navegação, consumo dos endpoints do backend e apresentação visual dos perfis, bibliotecas, listas de desejos e recomendações de compatibilidade.

Tecnologias Utilizadas: TypeScript, CSS, HTML, Angular e Angular Material

Acessar: https://enreliuk.github.io/Famify/#/inicio
